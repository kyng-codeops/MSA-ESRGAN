Multi-scale attention U-Net discriminator

The attention U-Net discriminator architecture, includes a downsampling encoding module, an upsampling decoding module, and several attention blocks. The core of this architecture lies in the attention mechanism, which assigns different weights to different regions of the image, thereby enhancing the perception of complex structures and details. Specifically, the downsampling encoding module gradually reduces the spatial resolution while extracting high-level semantic features; the upsampling decoding module progressively restores the spatial resolution while combining high-level features from the encoding phase to achieve detail reconstruction.

The CSAFM mainly consists of CAM and SAM detailed below. These modules enhance important features and suppress irrelevant ones by calculating weighted sums of the input features.

Attention gates were initially used for semantic segmentation in 3D medical images, and we have now adapted and applied them to the super-resolution task for 2D images. By incorporating features of different scales within the attention modules, we capture richer contextual information in the images, leading to superior performance in detail restoration.

Additionally, drawing from the Real-ESRGAN framework, we incorporated spectral normalization regularization to enhance the stability of the training process. Spectral normalization standardizes the network weights by limiting the norm of feature mappings, thus improving the stability and convergence speed of the model training. This regularization method is particularly important in training adversarial generative networks (GANs) as it effectively mitigates mode collapse and gradient vanishing issues.

The overall architecture of the multi-scale attention discriminator starts with 4 encoding downsampling blocks and 4 upsampling blocks.  However, to upsample the last 3 downsamples, we introduce an "Channel and Spatial Attention Fusing Module" (or CSAFM) that fuses the outputs from appropirate downsampled outputs and newly upsampled outputs of equal size.  Example, the very first input is HxWx3 and outputs as HxWxC. As HxWxC becomes input to the next encoding block it downsamples and outputs as (H/2)x(W/2)x2C, and that gets downsampled to (H/4)x(W/4)x4C, and downsampled again to (H/8)x(W/8)xC.

In the upsampling process, the very last downsampling block sends the (H/8)x(W/8)x8C output into an upsampling block that uses RelU, Conv, Spectral Norm, and RelU and outputs (H/4)x(W/4)x4C.

However, in the next upsampling block, the (H/4)x(W/4)x4C outputs from the 3rd encoder downsample, and the first upsampling block go into the CSAFM or "Channel and Spatial Attention Fusing Model" before going into the same upsampling process of the first upsampler block (RelU, Conv, Spectral Norm and ReLU).  The process repeats going to the next upsampling block where the two sets of (H/2)x(W/2)x2C outputs are fused before upsampling.  The forth and last upsampling fuses the HxWxC outputs before going into the last two blocks of extra convolutions. Each of these two convolution blocks consist of Conv, Spetral Norm and RelU.  Each of those inputs and outputs remain at the HxWxC dimensions.

As for the CSAFM module.  It takes two inputs, X and Y.  First X and Y are joined by element-wise addition which is sent into a channel attention module (or CAM), the output of the CAM is sent into a spatial attention module (or SAM).  The SAM sends its single output in three paths (or directions), the first one is combined with X using element-wise multiplication, the second one is combined with Y using element-wise multiplication, and the third is combined with the output of the previous two using element-wise addition forming one consolidated output called Z.  Basically Z is just the fused output of the X and Y inputs to the CSAFM.

The CAM module consistst of the following: The input is sent down two parallel paths.  The first path takes the input of the CAM and puts it through a block of AvgPool, Conv then sends that to a block of RelU, Conv, BatchNorm and that output is combined with the output of the second path using element-wise addition. The second path takes the input of the CAM and does a Conv then passes its output into a block that does (BatchNorm, ReLU, Conv, BatchNorm).  This is the output of that second path that gets combined to the first path of the CAM mentioned earlier. The element-wise combined paths outputs are then passed into sigmoid.  the sigmoid output is joined with the original CAM input using element-wise multiplication and this forms the output of the CAM.

The SAM module has only one path. It takes input, and puts it through the first block which consists of MaxPool, AvgPool, then passes that to the next block of Conv, Sigmoid, and that becomes the output of the SAM.

Spatial attention module(SAM) utilizes the spatial relationship of features to generate a spatial attention map. Unlike channel attention, spatial attention focuses on “where” the informative parts are, complementing channel attention. To calculate spatial attention, we first apply average pooling and maximum pooling operations along the channel axis and concatenate them to generate an efficient feature descriptor. Applying pooling operations along the channel axis has been proven effective in highlighting informative regions. On the concatenated feature descriptor, we apply a convolution layer to generate the spatial attention map M_s(X) \in {\mathbb {R}}^{H \times W}, which encodes locations to emphasize or suppress. We describe the detailed operations below. We aggregate the channel information of the feature map through two pooling operations to generate two 2D maps: X_{avg}^s \in {\mathbb {R}}^{1 \times H \times W} and X_{max}^s \in {\mathbb {R}}^{1 \times H \times W}. Each represents the average pooling feature and the maximum pooling feature across channels. Then, they are concatenated and convolved through a standard convolution layer to generate a 2D spatial attention map. In short, the calculation formula for spatial attention is:

begin{aligned} M_s(X) = \sigma (\text {Conv}^{7 \times 7}([\text {AvgPool}(X); \text {MaxPool}(X)])) = \sigma (\text {Conv}^{7 \times 7}([X_{avg}^s; X_{max}^s])) \end{aligned}
(4)

where \sigma denotes the sigmoid function, \text {Conv}^{7 \times 7} denotes the convolution operation with a kernel size of 7x7, X represents the input, \text {AvgPool} represents average pooling, and \text {MaxPool} represents maximum pooling.
